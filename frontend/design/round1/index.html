Round 1 — Typography Directions A–J

Ten independent typography-led design directions for the Wind Forecast Decision Portal. Each direction uses only type, flat background color, text color, and whitespace—no borders, shapes, icons, images, gradients, shadows, or SVG. Open each direction to evaluate, then lock one for Round 2 production implementation.

Direction A — Cutoff Line

Hard temporal boundary as vertical rule.

Monospace (data) + Sans (ui) • 2-color

Direction B — Vintage Stack

Forecast revisions as typographic depth.

Variable weight axis • 3-color

Direction C — Half-Hour Grid

48-period rhythm as baseline grid.

Tabular numerals, tight leading • 1-color

Direction D — Meridian Anchor

Greenwich vertical as reading spine.

Serif display + mono data • 2-color

Direction E — Risk Polarity

Over/under forecast as warm/cool text.

Single variable font, weight/width axes • 4-color

Direction F — Publication Moment

"As of" timestamp as dominant mark.

Display serif + mono • 2-color

Direction G — Buyer's Shortfall

Shortfall risk as visual weight.

Condensed sans, tight tracking • 3-color

Direction H — Forecast Horizon

Distance from cutoff as fade/scale.

Single font, size/opacity gradient • 2-color

Direction I — Actual vs Forecast

Two voices, one timeline.

Paired serif/sans dialogue • 3-color

Direction J — Decision Window

Narrow actionable moment.

Wide sans, generous whitespace • 1-color

Constraints (all directions)

  • System fonts only — no Google Fonts, no external CDN (isolation protocol)
  • No new dependencies — existing Tailwind + ECharts stack only
  • Dark mode considered palette, not inversion
  • London timezone — D-1 09:00 cutoff, half-hourly periods
  • Self-host WOFF2 in public/fonts/ if a specific font is locked
